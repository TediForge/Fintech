# Suggest a Feature

The page contains two tabs

- Suggestions
- Feature Requests

Use mock data only for now

---

# Suggestions

Purpose

Allow users to suggest improvements to features that already exist in the app

## Fields

### Suggestion Title

A short summary of the suggestion

Required

Maximum 80 characters

### Category

Examples

- App Experience
- Wallet
- Payments
- Cards
- Rewards
- Security
- Notifications
- Settings
- Other

Required

### Suggestion

Describe the improvement in detail

Required

Minimum 20 characters

Maximum 3000 characters

### Expected Benefit

Explain how this suggestion would improve the app or the user experience

Optional

### Attachments

Allow users to attach screenshots or images

Optional

Support multiple attachments

### Submission Notice

Display before submission

By submitting feedback you agree that your suggestions and ideas may be used by Tediwave without compensation and may become part of our products or services

# Feature Requests

Purpose

Allow users to request completely new functionality that does not currently exist in the app

## Fields

### Feature Name

A short name for the requested feature

Required

Maximum 80 characters

### Category

Examples

- Wallet
- Payments
- Cards
- Rewards
- Security
- Business
- API
- Other

Required

### Feature Description

Describe the feature in detail and explain how it should work

Required

Minimum 30 characters

Maximum 5000 characters

### Why Is This Feature Needed

Explain the problem this feature would solve

Required

### Expected Outcome

Describe how users would benefit from this feature

Optional

### Attachments

Allow users to attach screenshots mockups or images

Optional

Support multiple attachments

### Submission Notice

Display before submission

By submitting feedback you agree that your feature requests ideas and concepts may be used by Tediwave without compensation and may become part of our products or services
