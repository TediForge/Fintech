# Report a Bug

Purpose

Allow users to report bugs crashes unexpected behavior or issues they encounter while using the app

Use mock data only for now

## Fields

### Bug Title

Provide a short summary of the issue

Required

Maximum 80 characters

### Category

Examples

- App Crash
- Login
- Registration
- Wallet
- Payments
- Deposit
- Withdrawal
- Transfer
- Transactions
- Cards
- Rewards
- Notifications
- Security
- Settings
- Performance
- User Interface
- Other

Required

### Severity

Allow users to indicate how serious the issue is

Options

- Low
- Medium
- High
- Critical

Required

### Description

Describe the issue in detail including what happened and what you expected to happen

Required

Minimum 30 characters

Maximum 5000 characters

### Steps to Reproduce

Allow users to describe the exact steps that reproduce the issue

Example

- Open the Wallet screen
- Tap Deposit
- Select Card Deposit
- Enter an amount
- Tap Continue
- App closes unexpectedly

Required

### Expected Result

Describe what should have happened

Required

### Actual Result

Describe what actually happened

Required

### Attachments

Allow users to attach screenshots screen recordings or images

Optional

Support multiple attachments

### Submission Notice

Display before submission

By submitting this bug report you agree that the information and attachments you provide may be used by Tediwave to investigate reproduce and resolve the reported issue
